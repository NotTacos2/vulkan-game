# Cube Collector
This is similar to my OpenGL game, Teapot Collector, however this is made using Vulkan and has additional features.

## Renderer
- Basic Vulkan Rendering (with renderpass, pipeline, and etc)
- Reliable Swapchain
- Performance Vertex and Depth Buffering
- Index Drawing
- OBJ and MTL Loader
- Sky rendering with cubemaps
- Fragment and vertex shaders

## Game
- Basic collision
- Scoring by updating windows name
- Random location for cube
- Basic Character Movement with turning
